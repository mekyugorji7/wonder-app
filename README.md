# Wonder

<img width="1496" height="860" alt="wonder-ss" src="https://github.com/user-attachments/assets/f1cc193d-1c6e-425a-a03e-8896ed0d509a" />

Wonder is the agentic creative workspace for all your business content. The platform helps businesses create websites, graphic designs, social media posts, print materials, and much more. This repository contains its React-based landing page and product experience. (WIP)

Built with Vite, React, TypeScript, Tailwind CSS, Motion, Iconoir, and shadcn-style UI components.c

## Installation

Prerequisite: Node.js 18 or later.

```bash
npm install
```

## Developing locally

Start the development server:

```bash
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173) in your browser.

### Available scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build
